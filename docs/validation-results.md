# 验证结果与覆盖范围

本文汇总实际执行的自动化检查、打包校验和真实桌面操作。测试方法见 [VALIDATION.md](VALIDATION.md)，Windows 接入见 [WINDOWS.md](WINDOWS.md)。测试均使用一次性 Fixture；原始本机日志、截图、配对凭据和临时 Agent 配置不随源码公开。

## 当前标识与验证版本

2026-09-27 将宿主应用标识统一为 `com.starroy.computeruse`，macOS Fixture 标识为 `com.starroy.computeruse.fixture`。新标识已通过 TypeScript、Swift 测试及 macOS 开发包构建和签名校验。

下述 2026-09-24 至 2026-09-26 的桌面实测发生在更名前的开发版本上，不能代替新标识版本验收。macOS 仍需重新授予权限、配对 Fixture 并复跑桌面流程；Windows ARM64 当前版本的限定验收结果见下一节。x64 包仍需重新构建并在原生 x64 桌面验证。历史 ZIP 不代表当前源码。

- Mac `pnpm check`：Vitest 90/90、脚本测试 6/6 通过。
- Windows `pnpm check`：Vitest 73 项通过、17 项平台跳过；脚本测试 5 项通过、1 项平台跳过。跳过项不计作通过。

- 当前源码的 WinForms / Win32 / WPF Fixture 已构建，新宿主及三个 Fixture 均在交互会话启动；本轮建立了仅包含该 Fixture 可执行路径的新配对。

| 控件 | 后台会话 | 经用户在宿主批准的前台会话 | 独立结果 |
|---|---|---|---|
| WinForms TextBox | 1 次短文本、10 次混合长文本 | 1 次短文本、10 次混合长文本 | 22/22 全文准确，每轮 Record 计数为 1 |
| Win32 EDIT | 1 次短文本、10 次混合长文本 | 1 次短文本、10 次混合长文本 | 22/22 全文准确，每轮 Record 计数为 1 |
| WPF TextBox | 1 次短文本、10 次混合长文本 | 1 次短文本、10 次混合长文本 | 22/22 全文准确，每轮 Record 计数为 1 |

长文本包含中英文、数字和表情，长度为 165–183 个 UTF-16 单元。66 个用例共派发 198 个动作：66 次 `type` 返回 `executed`，132 次 Reset / Record 点击返回 `unknown`。每次动作均使用新快照并查询原请求状态；按钮效果由独立结果文件确认，没有自动重发，也没有将原状态改写为成功。

另以独立 Win32 / UI Automation 读回监测控件全文和前台进程，目标采样间隔 100 毫秒。所有 66 个用例在输入结束后的延迟观察时段内，实际控件值均与预期全文一致，未记录到继续输入；各输入时段内未采样到焦点切换。此结果不能排除采样间隙内的瞬态变化，也不覆盖人机同时输入。

真实 Mac Codex 使用临时 HTTP MCP 配置，经 SSH 完成一轮 WPF 后台操作：13 次 MCP 调用包含 4 次返回图片的观察、3 次动作、2 次不确定状态查询及会话关闭。模型没有使用终端或其他电脑工具操作 Fixture。独立文件确认 95 个 UTF-16 单元全文准确且 Record 计数为 1；模型明确没有把单行截图当成全文证明。此处是 **1 次真实模型回归**，未完成发布门槛要求的 10 次模型任务成功率评估。

边界与生命周期检查：

- MCP 只列出新配对路径的三个 Fixture 窗口；未配对目标会话被拒绝，无凭据 HTTP 返回 401。
- 相同请求 ID 与参数返回已有记录，独立计数不增加；相同 ID 改参数、重复使用已消费快照及伪造元素引用均被拒绝。
- 托盘暂停后动作被拒绝且无效果，恢复后可重新观察。前台请求超时以及在宿主点击“否”均返回 `permission_denied`，没有输入效果。
- Record 发出后主动断开 SSH，调用方收到传输错误；重连只查询状态并观察，状态保持 `unknown`，独立计数只增加 1，未重放。
- **空闲状态**紧急停止后 Node、驱动和 HTTP 监听均退出，Fixture 文件无额外变化；重启后可重新截图，原不确定动作记录仍为 `unknown`，没有重放。尚未验证按键或鼠标按住期间的释放。
- 托盘撤销本轮客户端后，旧凭据立即返回 401。托盘正常退出后，宿主、Node、驱动均退出，HTTP 不再监听。
- SYSTEM 身份读取私有管道发现文件及连接命名管道均被拒绝；不替代普通第二用户隔离测试。
- 窗口监测以 10 毫秒为目标采样间隔，监测期间记录到 18 次新可见窗口事件，没有控制台窗口事件；用户也报告本轮未看到黑框。采样不证明任意短暂闪现绝不发生。

验收后清理本轮配对凭据、临时隧道和监测任务，新宿主重新打开并保持 HTTP 默认关闭；未修改用户级或项目级 Codex 配置。

该提交存在一项授权提示体验问题：请求超时后宿主弹窗不会自动关闭；晚点“是”可能显示“已批准请求”，但运行时已经拒绝，CLI 配对或会话仍失败。实际授权保持失败关闭。此问题已在下述后续修复中处理，旧 ZIP 不包含修复。

本机导出包为 `computer-use-0.1.0-windows-arm64-f8fcdd6.zip`，125,829,620 字节；Windows 与 Mac 计算的 SHA-256 一致：`231500dc8bcb8a00929755793ecdfeee709e2fa9ddcdbeeef618a4cd49e4b56d`。ZIP 完整性检查通过；在 Windows 重新解压后，内置 Node、Cua 驱动及原生 SDK 加载验证通过。这是未签名便携内测包，不是已发布安装器。

### Windows 授权窗口生命周期修复（2026-09-27）

## macOS 桌面与模型接入（2026-09-24）

经授权的 AppKit Fixture 完成 10 轮后台 Reset → type → Record。每轮由独立结果文件确认清空已发生、中文全文准确且计数仅增加一次。共 30 个动作：10 次输入返回 `executed`，20 次按钮派发返回 `unknown`；后者仅由独立文件证实效果，没有重放或更改原动作状态。截图和辅助功能元素均实际返回，但 `elementsComplete: false`，不能据此证明未列出的元素不存在。

真实 Codex 模型经临时 stdio MCP 配置读取截图、输入中文、点击 Record，并对 `unknown` 查询状态和重新观察。独立结果文件确认文字准确且计数增加一次。协议握手测试和模型调用分别执行；此次调用不覆盖任意应用或完整创作任务。

开发中曾遇到重签名后权限不匹配，以及宿主等待管道缓冲填满导致就绪消息超时。后者通过有界读取修复并增加回归测试。SDK 连接过期处理已通过模拟测试，长时间真实桌面重连仍需补测。

## Windows 文本控件与点击（2026-09-25）

配对范围仅为一次性测试程序的规范化可执行文件路径。测试程序分别使用 WinForms `TextBox`、原生 Win32 `EDIT` 和 WPF `TextBox`，记录文本变化，并在 Record 时写入完整文本和记录计数。前台会话经过托盘批准。

| 控件 | 测试范围 | 独立验证结果 |
|---|---|---|
| WinForms | 后台和获批前台各 1 次短文本、10 次 165 个 UTF-16 单元的中英数字表情混合文本 | 22 次输入全文准确、每次记录一次；延迟复查无续写 |
| Win32、WPF | 每种控件在后台和获批前台各 1 次短文本、10 次混合长文本；长文本约 180–189 个 UTF-16 单元 | 共 44 次输入全文准确、每次记录一次；延迟复查无续写 |
| WPF 元素点击修复后 | 12 次独立前台会话的 Reset 元素点击；另对 WPF 和 Win32 各执行短文本、长文本完整流程 | 12 次会话均能继续观察并正常关闭；完整流程结果准确、记录一次 |

Windows 前台键盘路径曾出现长文本部分到达；WPF 元素点击的前台派发曾触发运行时安全停机。当前实现对带有最新快照 `elementId` 的 `type` 和 `click` 使用 Cua 后台辅助功能路径，即使会话已获前台批准。拒绝或结果不确定时不回退、不重发。旧点击路径的底层系统错误仍未确认，不能据此保证所有控件都不会发生驱动故障。

输入是否只执行一次以单次派发、全文及 Record 计数为依据；辅助功能赋值可能产生多个文本变化事件。按钮派发仍可能返回 `unknown`，独立验证没有将其返回状态改成 `executed`。

以 100 毫秒间隔采样活动窗口，在覆盖的 11 次 WPF 和 9 次 Win32 长文本输入时段未记录到焦点切换。按钮点击附近会短暂激活 Fixture；采样不能排除短于 100 毫秒的焦点变化。

## Windows 远程 MCP 与真实模型（2026-09-25）

链路为 Mac Codex → SSH 本地转发 → Windows 回环 HTTP MCP → Windows 桌面驱动。MCP 仅监听 Windows `127.0.0.1:47631`，凭据由 Mac 私有文件通过 header helper 提供，测试没有修改用户级或项目级 Agent 配置。

真实模型收到 Windows PNG 截图，完成观察、输入、点击、状态查询和关闭会话。长文本模型测试分别由 WinForms 独立文件确认 129 个 UTF-16 单元、由修复后的 WPF 独立文件确认 68 个 UTF-16 单元全文准确且记录一次。模型只从截图确认可见文本开头和记录次数，没有将单行框截图当作全文验证。遇到 `unknown` 时查询状态并重新观察，未重放。

授权与中断验证结果：

- `targets` 仅显示配对 Fixture；托盘撤销后旧 HTTP 凭据立即返回 401。
- 前台批准被拒绝时返回 `permission_denied`；批准后才能使用相应会话。
- Record 发出后断开 SSH，调用方收到传输错误；重连后动作状态为 `unknown`，独立计数确认只新增一次，未自动重发。
- 托盘退出后，宿主、Node 和驱动进程均结束。
- 以 SYSTEM 身份访问当前用户管道发现文件及连接管道均被拒绝；这不替代普通第二用户测试。
