These images show the native Connect pages used by the v0.7.0 onboarding flow. They are unmodified captures, not mockups.

| File | Source |
| --- | --- |
| `macos-connect.png` | Captured on 2026-10-12 from the locally installed macOS App, showing the simplified Connect page in Chinese. |

The captures use local builds prepared before the v0.7.0 release. They illustrate the UI and do not establish acceptance of downloaded release artifacts or successful setup in a third-party Agent. See [onboarding validation](../validation-skill-link-20261012.md) for the tested scope.
